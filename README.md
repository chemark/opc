# OPC 资源库

OPC（One Person Company，一人公司）是 AI 时代的新型创业模式：一个人借助 AI 工具，独立完成产品开发、运营、销售的全链路。

本仓库收录 OPC 相关的政策解读、社区资源、研究报告和实用工具，面向有意在国内从事 OPC 创业的独立开发者和创业者。未来计划基于此内容搭建一个公开网站。

## 已有内容

### [wuhan-opc/](wuhan-opc/)

武汉市是目前国内 OPC 政策力度最大的城市之一。2025 年起，武汉市、武昌区等多级政府相继出台政策，提供免租空间、算力补贴、购房优惠、人才计划等支持。

收录内容：政策链接、社区清单、独立开发者资源手册、多模型研究报告、AI 提示词。
