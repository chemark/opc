# 武汉 OPC 资源库

武汉市人工智能 OPC（一人公司）政策与社区资源的整理汇总。

OPC 是武汉市重点支持的创业新模式——借助 AI，一个人也能跑起一家公司。2025 年起，武汉市、武昌区等多级政府相继出台政策，提供免租空间、算力补贴、购房优惠、人才计划等支持。

本仓库记录政策、社区、研究报告和 AI 工具提示词，未来计划基于此内容搭建一个公开网站。

## 背景

2025 年 2 月，武汉市政府发布《武汉市支持人工智能 OPC 创新发展若干措施》（十条），围绕算力、数据、模型、人才、金融等环节给予支持。武昌区、光谷、小洪山等片区也陆续推出各自的 OPC 专属社区和优惠政策。

本仓库持续更新中。
