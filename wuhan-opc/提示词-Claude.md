# 详细研究要求

## 1. Top 5 赚钱方向分析

每个方向必须包含：
- 市场需求（规模 / 增长趋势）
- 竞争程度（红海 / 蓝海 / 细分切口）
- 启动成本（金钱 + 时间）
- 收入天花板（月收入上限估算）
- 与研究对象画像的匹配度（高 / 中 / 低，并说明原因）
- 推荐切入点（非常具体，例如"做 XX 类 App，主攻 XX 关键词，定价 XX 元/月"）

## 2. 案例拆解

每个案例必须包含：
- 产品类型与定位
- 收入结构（订阅 / 广告 / 一次性 / 混合）
- 流量来源（App Store SEO / 内容 / 社区 / 投放等）
- 增长路径（从 0 到第一笔收入，再到稳定收入）
- 可复制性分析（哪些动作可以照搬，哪些不可复制）

案例来源优先级：武汉本地 > 国内其他城市 > 海外 Indie Hacker

> ⚠️ 如果找不到公开来源的真实案例，请使用"基于社区观察的合成案例"并明确标注，不要编造具体姓名或公司名。

## 3. 政策与环境

重点输出**实际可操作**的政策，包括：
- 武汉针对个体户 / 小微企业 / 数字经济的补贴
- 税收优惠（核定征收、增值税免征等）
- 创业园区（入驻条件、实际好处）
- 申请难度与落地可行性（高 / 中 / 低）

> ⚠️ 避免列出"原则性政策"，只列出开发者个人实际能申请的资源。

## 4. 武汉 vs 杭州对比

使用表格对比以下维度：

| 维度 | 武汉 | 杭州 |
|------|------|------|
| 独立开发氛围 | | |
| 生活成本（房租 / 餐饮） | | |
| 政策支持力度 | | |
| 技术/互联网生态 | | |
| 机会密度 | | |
| 适合的开发者类型 | | |

最后给出明确结论：对于本研究对象，推荐哪个城市，理由是什么。

## 5. 6–12 个月行动路径

分三阶段输出：

**阶段一（0–2个月）：验证期**
- 目标：找到第一个付费用户
- 具体行动

**阶段二（3–6个月）：起步期**
- 目标：月收入稳定 5000–1万
- 具体行动

**阶段三（7–12个月）：增长期**
- 目标：月收入 1万–3万
- 具体行动

同时输出：
- 最大风险（Top 3）
- 常见坑（独立开发者容易踩的错误）

# 数据可信度规则（必须遵守）

对每一处数据或判断，标注以下之一：

- `[来源: XXX]` — 有明确公开来源
- `[估计]` — 基于行业常识推算，无直接数据
- `[推测]` — 主观判断，置信度较低
- `[合成案例]` — 非真实单一案例，基于多个来源综合

**如果某个研究问题信息严重不足，请直接说明信息缺口，并给出补充研究建议，不要用模糊语言掩盖。**
