> OPC = One Person Company（一人公司 / 超级个体）
> 本文档整理于 2026年4月，聚焦武汉本地独立开发者可实际落地的信息。

## 一、能真正拿到手的政策（精简版）

武汉政策文件很多，但真正对个人开发者有价值的只有以下几项：

### ① 算力补贴（最值得关注）
- AI 调用费用报销 **50%，最高 20 万元/年，最长 3 年**
- 各区每年免费划拨 **≥ 2000 卡时**算力包
- 适用条件：方向涉及 AI 调用或开发即可，门槛中等偏低，目前红利期刚开始

### ② 高校毕业生一次性创业补贴
- 金额：**5000 元**（一次性现金）
- 条件：毕业 **5 年内**、首次创办小微企业或个体工商户、经营 6 个月以上、带动就业 2 人（需招兼职/实习生并缴社保）
- 落地可行性：**中**，金额不大但流程相对简单

### ③ 税收优惠（全国普适，自动享受）
- 增值税：小规模纳税人**季度销售 ≤ 30 万免征**，超出按 1% 征收（政策延续至 2027 年底）
- 所得税：年应纳税所得额 ≤ 100 万，减按 **5%** 征收
- 操作：正常注册个体工商户即自动适用，**MRR ≤ 1 万美金时几乎零税负**

### ④ 创业贷款
- 个人创业担保贷款：最高 **30 万元**，最长 3 年
- OPC 企业贷款：最高 **500 万元**

### ⑤ 人才租房 / 购房补贴
- 租房：按博士标准，2 年内每月最高 **2000 元**补贴，第 3 年按市场价 70% 缴租
- 购房：每平方米 1000 元，最高 **10 万元**购房补贴

> **注意**：核定征收（网上热议的"0.6% 税率"）在武汉本地可行性低，年营收 50 万以下不要折腾，老老实实用小规模纳税人优惠。

## 四、行动路径（0 → 1 万 → 3 万）

**核心原则：现金流和产品必须并行，不要先干完一个再干另一个。**

### 阶段一（0–2 个月）：验证期
**目标：拿到第一个付费用户**

- **产品**：选 1 款出海 AI 小工具 SaaS 做 MVP（从 Toolify 200–500 名产品中找方向）
- **现金流**：程序员客栈 / Upwork 接 2–3 个短单，每月 5000–10000 元保底
- **内容**：小红书 + 即刻 Build in Public，20 条内容（不追粉丝，追学习曲线）
- **具体步骤**：
  1. 第 1 周：个体工商户注册 + 开对公账户 + 挂接单档口
  2. 第 2 周：写 BRD（需求 + 定价 + 流量方案）
  3. 第 3–6 周：做 MVP（域名 + Vercel + Stripe + OpenAI API）
  4. 第 7–8 周：Product Hunt 发布 + Reddit 发帖 + 英文 SEO 写 10 篇 blog

### 阶段二（3–6 个月）：起步期
**目标：月稳定 5000–1 万**

- **产品**：出海 SaaS MRR $300–$1000；同时上线 1–2 款国内 iOS 小工具 App
- **现金流**：外包接单砍半（每月 3000–5000 元），释放 50% 时间给产品
- **里程碑**：月 6 末 MRR ≥ 5000 元进入阶段三；< 3000 元回到阶段一重选赛道

### 阶段三（7–12 个月）：增长期
**目标：月 1 万–3 万**

- **产品**：出海 SaaS 扩到 2–3 个产品组合，MRR $1000–$3000；国内 iOS 矩阵 2–4 款
- **现金流**：放弃外包，除非有 1–2 天快速交付的熟客单
- **关键动作**：
  - 月 7–8：给跑通的 SaaS 投 Google Ads / Reddit Promoted（月预算 $300–$500 测试 ROAS）
  - 月 10：国内 iOS App 涨价测试（38 元/年 → 58 元/年，或 128 元买断）
  - 月 12：删掉所有 MRR < $100 的僵尸产品，集中放大头部 2 款

## 五、避坑指南

### 产品方向
- **不要做大而全**：2026 年玩法是"1 个 App 1 个场景"，越小越好
- **先验证再开发**：先做 Landing Page 收集邮箱，100 人有兴趣再开发 MVP
- **3 个月硬性规则**：任何产品 MVP 4 周内必上线；3 个月内仍无付费用户必须砍掉换赛道，不解释

### 变现定价
- 国内市场对"月订阅"反感，应做**年订阅 38–98 元**或**买断 128–298 元**
- 出海产品：订阅制（月费 $9–$15）+ Product Hunt / Reddit 冷启动

### 竞争风险
- 好点子会迅速被复制（案例：Seeu.food 一个月内出现 20+ 克隆），需快速迭代形成差异化
- 不拼 AI 深度，拼**场景深度**——"垂直领域 × 简单 AI 封装"

### 外包接单（作为现金流来源）

**接单策略**：只接两类单——2 周内交付的 iOS/前端小项目、海外 Upwork 英文单（溢价 2–3 倍）。技术边界清晰：只接"纯前端展示"和"纯调大模型 API 套壳"，遇到复杂后端果断转包。

#### 国内平台

**① 程序员客栈**（推荐度：★★★★☆）
- 地址：[coder.work](https://www.coder.work)
- 定位：最主流的国内开发者 B 端接单平台，需求方多为小公司/产品经理
- 单价参考：全栈 500–800 元/天，iOS 原生 800–1500 元/天
- 优势：需求真实，有平台担保，审核简单；支持"竞标"和"直接邀约"两种方式
- 劣势：国内竞争激烈，单价被压；需要完善技能标签才能被搜索到
- **上手动作**：注册后完善 iOS + 前端技能标签，上传 2–3 个作品截图，设置日费报价，开启"可接单"状态

**② 电鸭社区**（推荐度：★★★★☆）
- 地址：[eleduck.com](https://eleduck.com)
- 定位：国内最好的远程工作/自由职业社区，氛围比程序员客栈更好；既有短期项目也有长期远程岗位
- 单价参考：项目制为主，iOS/前端项目 5000–30000 元/项
- 优势：用户质量高、需求方靠谱，有讨论区可以观察行情；部分需求为海外公司发布
- 劣势：需求量比程序员客栈少，竞争者也更专业
- **上手动作**：在社区发一篇"我在接单"的帖子（包含技能、过往作品、联系方式），比单纯挂简历效果好

**③ V2EX 酱**（推荐度：★★★☆☆）
- 地址：[v2ex.com/go/jobs](https://www.v2ex.com/go/jobs)
- 定位：V2EX 技术社区的外包/招聘版块，发帖免费；技术人聚集，需求质量参差不齐
- 单价参考：差异极大，从几百到数万不等
- 优势：零门槛，直接发帖或回复需求帖；技术圈口碑传播快
- 劣势：无担保机制，需自行甄别需求真实性；诈骗需求较多，要谨慎
- **上手动作**：发一篇"[接单] iOS + 前端 + AI 接入，武汉，可远程"的帖子，包含微信/邮件联系方式

**④ 猪八戒**（推荐度：★★☆☆☆，仅练手用）
- 地址：[zbj.com](https://www.zbj.com)
- 定位：综合型服务外包平台，需求量大但单价极低，主要是个体/小微商家
- 单价参考：一个微信小程序 500–3000 元（严重被压价）
- 优势：需求多，新人容易拿到首单积累经验
- 劣势：价格战严重，不适合长期；需求描述模糊，改需频繁
- **建议**：只在刚开始没有任何案例时用，拿 1–2 个好评后立即转到程序员客栈/电鸭

#### 海外平台（溢价 2–3 倍，重点方向）

**⑤ Upwork**（推荐度：★★★★★）
- 地址：[upwork.com](https://www.upwork.com)
- 定位：全球最大综合自由职业平台，时薪制 + 固定价格均有；iOS/前端 + AI 需求大量存在
- 单价参考：新人起步 $20–$30/h；积累好评后 $40–$60/h；iOS 项目 $500–$3000/项
- 优势：平台有担保，资金安全；需求体量大；中国开发者有时差优势（美国下班=中国早晨，抢先投标）
- 劣势：新账号前 3 个月需靠低价拿首单积累评分；平台抽成 10–20%；需要英文沟通
- **上手 SOP**：
  1. 注册时选"Individual"，认真填写 Title（如"iOS & React Developer | AI API Integration"）
  2. 每天早 6–8 点（美国傍晚发包高峰）用关键词 `[iOS] OR [React] + [ChatGPT API]` 搜索新发布的单子
  3. 前 5 个单子专挑"修 bug / 小改动"类，竞标信写："新人争好评，4 小时内交付，修不好不收钱"
  4. 每次交付附一个 3 分钟 Loom 录屏讲解，好评率极高

**⑥ Fiverr**（推荐度：★★★★☆）
- 地址：[fiverr.com](https://www.fiverr.com)
- 定位：服务"产品化"平台——卖的不是时间，而是标准化套餐（Gig）；买家主动搜索并下单
- 单价参考：基础套餐 $50–$150，进阶套餐 $200–$500；靠评价数量推高排名
- 优势：**被动收入**——上架后买家主动找你，不用天天投标；适合标准化的重复性工作
- 劣势：新 Gig 排名靠后，冷启动慢；平台抽成 20%
- **推荐 Gig 方向**（适合你的技能）：
  - "I will build a ChatGPT-powered iOS app UI in 3 days"
  - "I will create a React landing page with AI chatbot integration"
  - "I will add OpenAI API to your existing web app"
- **上手动作**：上架 2–3 个 Gig，每个 Gig 配高质量封面图（用 Canva 做），写清楚交付物和时间；前期主动在 Reddit 等地方宣传自己的 Fiverr 链接

**⑦ Toptal**（推荐度：★★★☆☆，长期目标）
- 地址：[toptal.com](https://www.toptal.com)
- 定位：高端开发者平台，号称只录取前 3% 的申请者；通过审核后时薪 $60–$150+
- 单价参考：$60–$150/h，远超其他平台
- 优势：需求方为正规企业，项目质量高；通过后竞争极小
- 劣势：审核极严（英文技术面试 + 代码测试 + 试用项目），新人通过率低
- **建议**：先在 Upwork 积累 6 个月评价再申请，当前阶段不优先

#### 其他渠道（零平台抽成）

**⑧ GitHub 钓鱼法**
- 在 GitHub 放一个好看的 AI 相关开源项目（如"ChatGPT React UI Template"），README 末尾加一行："Available for custom development — [hire me](mailto:你的邮箱)"
- 被动带来精准询问，无需投标，直接私域结算

**⑨ Twitter/X 私域接单**
- 关注 `#buildinpublic` `#indiedev` `#hiring` 标签，看到有人喊"找开发者"直接私信
- 建立 AI 开发相关的技术推文积累，每周发 1–2 条展示自己做的东西

**⑩ Telegram 接包群**（需自行搜索加入）
- 搜索关键词：`remote dev jobs`、`freelance iOS`、`outsource dev`
- 优势：零抽成，直接沟通；劣势：需甄别真实性

### 个体工商户 vs 公司：常见疑问

**Q：为什么注册个体工商户而不是公司？**

四个原因：
1. **收款自由**：个体户对公账户的钱可以直接转个人账户，无限制。公司资金随意转到个人账户在税务上会被认定为分红或工资，需缴个人所得税，操作麻烦
2. **税务极简**：季度收入 ≤30 万增值税自动免征，不用申报、不用做账、不用请代账公司（公司每月要花几百元请代账）
3. **注册/注销分钟级**：鄂汇办 APP 十几分钟搞定，免费，不需要验资。注销也是线上几步。公司注销要清税、登报公示，少则一个月
4. **早期用不到公司的功能**：公司的核心价值是有限责任保护 + 可以融资发股权，你现在接外包、卖订阅，这两项都不需要

**何时应该升级成公司**：① 有 VC 愿意投资，要求公司主体；② 年营收稳定超过 50–100 万需要税务优化；③ 需要招全职员工

**Q：个体工商户有什么缺点？**

实际会遇到的缺点只有两个：

1. **部分大客户不签个体户合同**：国企、上市公司、大型私企的采购流程要求对方是有限责任公司，偶尔会遇到。中小客户、产品经理个人发包、海外客户基本没有这个问题
2. **Stripe 无法以个体户身份直接注册**：做出海 SaaS 想用 Stripe 收款，中国区要求公司主体。绕法：用 Paddle / LemonSqueezy 代销（个人即可用），或注册香港公司（约 1000–2000 元/年）。等真正要上线收款再处理，现在不用管

理论上还有"无限责任"的缺点，但软件开发业务几乎不会产生大额债务，实际风险可忽略。

---

**Q：个体工商户有营业执照吗？**

有。注册完成后颁发**个体工商户营业执照**，和公司营业执照一样是正式工商登记证件，有统一社会信用代码（18位）。接外包签合同、开发票、开对公银行账户，都可以用这张执照。
